# 07-04 实现 AI 个性化学习建议

## 概述

本模块实现基于 DeepSeek API 的个性化学习建议生成功能。系统会查询学生的基本信息、成绩趋势、学习行为、家庭背景和风险预警等多维度数据，构造详细的 Prompt 发送给大模型，生成3条具体、可操作的个性化学习建议，并保存到数据库。

## 开发步骤

### 步骤 1：实现 `backend/services/suggestion_service.py`

创建了两个核心函数：

#### 1.1 `generate_suggestion(student_id: str) -> dict`

**功能**：为指定学生生成个性化学习建议

**实现流程**：

1. **查询学生基本信息**：从 `student` 表获取姓名、性别、年龄等
2. **查询成绩趋势**：从 `exam_score` 表获取各科目 G1/G2/G3 成绩，格式化为趋势字符串（如 `SUBJ_MATH: G1=5, G2=6, G3=6`）
3. **查询学习行为**：从 `learning_behavior` 表获取出勤率、学习时长、睡眠时长、动机水平等
4. **查询家庭背景**：从 `family_background` 表获取父母学历、职业、家庭收入、家庭支持等
5. **查询风险预警**：从 `risk_alert` 表获取最新的风险等级和风险因素
6. **判断分制**：根据 student_id 前缀判断分制（STU_F_ 为 0-100 分制，其余为 0-20 分制）
7. **构造 Prompt**：将所有数据整合为结构化的用户 Prompt
8. **调用 DeepSeek API**：temperature=0.7（允许一定创造性），max_tokens=1024
9. **保存到数据库**：将建议内容插入 `learning_suggestion` 表
10. **返回结果**：`{ student_id, suggestion }`

**系统提示词设计要点**：
- 角色定位：经验丰富的学业顾问
- 要求生成恰好3条建议，以"建议一/二/三："开头
- 每条建议包含问题诊断 + 具体行动方案
- 建议必须基于学生实际数据，不能泛泛而谈
- 成绩优秀侧重提升和保持，成绩较差侧重基础巩固

#### 1.2 `update_feedback(suggestion_id: int, feedback: str)`

**功能**：更新学习建议的学生反馈

**实现逻辑**：
- 校验 feedback 值，只允许 `satisfied` / `neutral` / `unsatisfied`
- 检查建议 ID 是否存在
- 更新 `learning_suggestion` 表的 `student_feedback` 字段

### 步骤 2：更新 `backend/routes/suggestion.py`

实现了3个 API 接口：

| 路由 | 方法 | 功能 | 请求参数 |
|------|------|------|---------|
| `/<student_id>` | GET | 查询学生的历史建议列表 | 路径参数：student_id |
| `/generate/<student_id>` | POST | 为指定学生生成新建议 | 路径参数：student_id |
| `/<suggestion_id>/feedback` | PUT | 提交建议反馈 | 路径参数：suggestion_id；JSON body：`{"feedback": "satisfied/neutral/unsatisfied"}` |

**错误处理**：
- 学生不存在 → 404 + 错误信息
- feedback 值不合法 → 400 + 错误信息
- 建议 ID 不存在 → 400 + 错误信息
- DeepSeek API 调用失败 → 500 + 错误信息

## 关键设计决策

1. **Prompt 设计**：将学生的多维度数据（成绩、行为、家庭、预警）全部纳入 Prompt，确保建议的个性化程度
2. **temperature=0.7**：比 NL2SQL 的 temperature=0 更高，允许模型在建议内容上有一定创造性，但不会偏离数据事实
3. **成绩趋势格式化**：将成绩数据格式化为 `SUBJ_MATH: G1=5, G2=6, G3=6` 的形式，让模型能直观看到成绩变化趋势
4. **分制判断**：根据 student_id 前缀自动判断分制，避免模型误解成绩含义
5. **反馈校验**：严格限制 feedback 值为三个枚举值，与数据库 ENUM 类型一致
