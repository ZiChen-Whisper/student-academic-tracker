## 步骤 1：安装 Node.js

**操作**：检测到系统未安装 Node.js，使用 `winget` 安装 Node.js LTS 版本。

```powershell
winget install OpenJS.NodeJS.LTS --accept-source-agreements --accept-package-agreements
```

**结果**：
- 安装版本：Node.js v24.16.0
- npm 版本：11.13.0
- 安装后需刷新 PowerShell 的 `$env:Path` 才能识别 `node` 和 `npm` 命令

```powershell
$env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User")
```

## 步骤 2：使用 Vite 创建 React 项目

**操作**：在项目根目录下使用 `create-vite` 创建 React 项目。

```powershell
npm install -g create-vite
create-vite frontend --template react
```

> 注：由于 `frontend` 目录已存在 `style-preview.html` 文件，先将其备份后清空目录再创建项目。

**结果**：Vite 成功创建 React 项目，包含以下默认文件：
- `package.json` — 项目配置
- `vite.config.js` — Vite 配置
- `index.html` — 入口 HTML
- `src/main.jsx` — 入口文件
- `src/App.jsx` — 根组件
- `src/index.css` — 全局样式

## 步骤 4：配置 Tailwind CSS 和 Vite

**操作**：编辑 `frontend/vite.config.js`，引入 Tailwind CSS 插件并配置开发服务器代理。

**最终配置**：

```js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    react(),
    tailwindcss(),
  ],
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:5000',
        changeOrigin: true,
      },
    },
  },
})
```

**要点**：
- 引入 `@tailwindcss/vite` 插件，使 Tailwind CSS 在 Vite 构建时自动处理
- 配置 `/api` 请求代理到 `http://localhost:5000`（Flask 后端地址），解决开发环境跨域问题

## 步骤 8：创建 App.jsx（根组件 + 路由）

**操作**：使用 `BrowserRouter` + `Routes` + `Route` 配置 4 个页面路由。

**路由配置**：

| 路径 | 组件 | 导航名称 |
|------|------|---------|
| `/` | Overview | 学情概览 |
| `/student` | Student | 学生详情 |
| `/nl2sql` | NL2SQL | AI 查询 |
| `/alert` | Alert | 风险预警 |

**Layout 组件**：
- 导航栏使用 `.liquid-nav` 样式，sticky 定位
- 导航项使用 `NavLink`，active 态应用 `.liquid-nav-item.active` 样式
- 内容区最大宽度 1200px，左右内边距 1.5rem
- 使用 `<Outlet />` 渲染子路由

---

## 步骤 9：创建 main.jsx（入口文件）

**操作**：Vite 默认生成的 `main.jsx` 已满足要求，无需修改。

```jsx
import { StrictMode } from 'react'

import './index.css'
```
