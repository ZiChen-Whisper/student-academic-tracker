## 步骤 1：完善 MetricCard 组件（支持颜色变体）

**操作**：在原有 `MetricCard.jsx` 基础上新增 `color` 属性，支持 `default`、`danger`、`success`、`warning` 四种颜色变体。

**修改内容**：

| 属性 | 变体 | 图标背景色 | 图标颜色 | 数值颜色 |
|------|------|-----------|---------|---------|
| `default` | 默认 | `rgba(11,101,101,0.08)` | `var(--primary)` | `#095050` |
| `danger` | 高风险 | `rgba(192,57,43,0.08)` | `var(--danger)` | `var(--danger)` |
| `success` | 及格/成功 | `rgba(26,138,90,0.08)` | `var(--success)` | `var(--success)` |
| `warning` | 警告 | `rgba(212,136,15,0.08)` | `var(--warning)` | `var(--warning)` |

**实现方式**：

- 新增 `colorStyles` 常量对象，定义每种颜色变体的 `iconBg`、`iconColor`、`valueColor`
- 组件接收 `color` 属性（默认值 `'default'`），根据属性值从 `colorStyles` 获取对应样式
- 图标容器 `.metric-icon` 的 `background` 和 `color` 通过 inline style 覆盖
- 数值 `.metric-value` 的 `color` 通过 inline style 覆盖

**使用方式**：

```jsx
<MetricCard icon="alert" label="高风险学生" value={5} color="danger" />
<MetricCard icon="check" label="及格率" value="85.3%" color="success" />
```

## 步骤 2：实现 Overview.jsx 学情概览页面

**操作**：完整重写 `Overview.jsx`，实现学情概览页面的所有功能。

### 页面布局

```
┌─────────────────────────────────────────────────┐
│  学情概览                                        │
├──────────┬──────────┬──────────┬──────────┤
│ 学生总数  │ 平均成绩  │ 高风险人数 │ 及格率    │
├──────────┴──────────┴──────────┴──────────┤
│  各科目平均成绩（柱状图）  │  风险等级分布（饼图）  │
├─────────────────────────────────────────────────┤
│  成绩分布（直方图）                                │
└─────────────────────────────────────────────────┘
```

### 数据获取

使用 `Promise.all` 并行请求 4 个后端 API：

| API 函数 | 路径 | 用途 |
|----------|------|------|
| `getOverview()` | GET /api/scores/overview | 学生总数、平均成绩、高风险人数 |
| `getScoreDistribution()` | GET /api/scores/distribution | 成绩分布直方图数据 |
| `getClassStats()` | GET /api/scores/class-stats | 各科目平均成绩、及格率 |
| `getAlertStats()` | GET /api/alerts/stats | 风险等级分布（高/中/低计数） |

**API 返回数据格式**（实测）：

- `/api/scores/overview`：`{ average_score: "59.58", high_risk_count: 995, total_students: 7655 }`
- `/api/scores/distribution`：`{ value: [{ count: 56, score_range: "0-4" }, ...], Count: 4 }`
- `/api/scores/class-stats`：`[{ avg_score: "10.38", class_id: "CLS001", pass_rate: "66.75", student_count: 397, subject_id: "SUBJ_MATH" }, ...]`
- `/api/alerts/stats`：`{ high: 995, low: 3231, medium: 3429 }`

### 指标卡片

4 个指标卡片使用 `MetricCard` 组件：

| 指标 | 图标 | 颜色变体 | 数据来源 |
|------|------|---------|---------|
| 学生总数 | Users | default | `overview.total_students` |
| 平均成绩 | TrendingUp | default | `overview.average_score`（保留1位小数） |
| 高风险学生 | AlertTriangle | danger | `overview.high_risk_count` |
| 及格率 | CheckCircle | success | 从 classStats 计算得出 |

**及格率计算逻辑**：
- 从 `getClassStats` 返回的班级统计数据中，每个班级每科目都有 `pass_rate`（百分比）和 `student_count`
- 加权计算总及格率：`总及格人数 / 总考试人数 × 100%`
- 代码实现：
  ```js
  totalPass += count * (pass_rate / 100);
  totalStudents += count;
  passRate = (totalPass / totalStudents * 100).toFixed(1) + '%';
  ```

### 各科目平均成绩柱状图

- 使用 Recharts `BarChart` 组件
- 数据处理：从 `classStats` 按科目聚合加权平均成绩
  - 遍历 classStats，按 `subject_id` 分组
  - 加权平均：`sum(avg_score × student_count) / sum(student_count)`
- 科目名称映射：`SUBJ_MATH` → 数学，`SUBJ_PORTUGUESE` → 葡萄牙语，`SUBJ_GENERAL` → 综合
- 图表配色遵循规范 §6：
  - 柱状图填充：SVG `linearGradient`，从 `#0b6565`（顶部）到 `rgba(11,101,101,0.3)`（底部）
  - 网格线：`rgba(11,101,101,0.05)`，0.5px
  - 坐标轴文字：`rgba(11,101,101,0.35)`
  - Tooltip：`rgba(0,0,0,0.7)` 背景，白色文字，圆角 0.5rem
- 柱状图顶部圆角：`radius={[4, 4, 0, 0]}`，最大宽度 48px

### 风险等级分布饼图

- 使用 Recharts `PieChart` + `Pie` 组件（环形图）
- 内半径 55px，外半径 90px，间距 2px
- 配色遵循规范 §6：
  - 低风险：`#1a8a5a`（success）
  - 中风险：`#d4880f`（warning）
  - 高风险：`#c0392b`（danger）
- 中心镂空：70px 白色圆，`rgba(255,255,255,0.85)` + `backdrop-filter: blur(4px)`，显示预警总数
- 底部图例：圆形色块 + 名称 + 数量

### 成绩分布直方图

- 使用 Recharts `BarChart` 组件
- 数据直接来自 `getScoreDistribution` API
- 默认显示 G3 阶段成绩，按区间分组（0-4, 5-9, 10-14, 15-20）
- X 轴数据键为 `score_range`，Y 轴数据键为 `count`
- 配色与各科目平均成绩柱状图一致（SVG `linearGradient` 渐变填充）

### 自定义 Tooltip

- 统一的 `CustomTooltip` 组件，应用于所有图表
- 样式：`rgba(0,0,0,0.7)` 背景，白色文字，圆角 0.5rem
- 数值格式化：数字保留1位小数

### 加载状态

- 数据加载中显示 "加载中..." 文字，居中显示（`minHeight: 50vh`）
- API 请求失败时在控制台输出错误，页面显示空数据状态（"--" 或 "暂无数据"）

## 步骤 4：复查修复

**操作**：对照 PLAN.md 8.2 逐项检查，发现并修复以下问题。

### 修复 1：成绩分布 API 数据提取路径

**问题**：`/api/scores/distribution` 实际返回 `{ value: [{ count, score_range }], Count }`，数据嵌套在 `value` 字段下，原代码 `distRes.data?.data || distRes.data || []` 无法正确提取数组。

**修复**：改为 `distRes.data?.value || distRes.data?.data || (Array.isArray(distRes.data) ? distRes.data : [])`。

### 修复 2：成绩分布 X 轴数据键

**问题**：API 返回的字段名为 `score_range`，原代码 XAxis 的 `dataKey` 使用了 `"range"`，导致 X 轴标签不显示。

**修复**：将 `dataKey="range"` 改为 `dataKey="score_range"`。

### 修复 3：柱状图渐变填充

**问题**：PLAN.md 规定柱状图填充为 `linear-gradient(180deg, var(--primary) 0%, rgba(11,101,101,0.3) 100%)`，原代码使用纯色 `#0b6565`。

**修复**：使用 SVG `<defs>` + `<linearGradient>` 实现渐变填充。Recharts v3 不再导出 `LinearGradient`/`Stop` 组件，改用原生 SVG 标签 `<linearGradient>` 和 `<stop>`。

```jsx
<defs>
  <linearGradient id="barGradient" x1="0" y1="0" x2="0" y2="1">
    <stop offset="0%" stopColor="#0b6565" />
    <stop offset="100%" stopColor="rgba(11,101,101,0.3)" />
  </linearGradient>
</defs>
<Bar fill="url(#barGradient)" />
```
