## 一、任务概述

实现 AI 自然语言查询（NL2SQL）页面，允许用户输入自然语言问题，由后端 AI 服务将问题转换为 SQL 并执行查询，前端展示生成的 SQL 和查询结果。

## 三、实现细节

### 3.1 示例问题标签

- 提供 8 个预设示例问题，使用 `.liquid-btn-sm .liquid-btn-pill` 胶囊小号按钮样式
- 点击示例问题直接触发查询，同时将问题填入输入框
- 示例问题列表：
  1. 查询所有学生的平均成绩
  2. 查询数学成绩前10名的学生
  3. 查询出勤率低于80%的学生
  4. 统计各科目的平均分
  5. 查询高风险预警学生名单
  6. 查询缺勤次数最多的10个学生
  7. 统计男女学生的平均成绩差异
  8. 查询各班级的平均成绩排名

### 3.2 输入区域

- 输入框使用 `.liquid-input` 样式，占位符"请输入您的问题..."
- 查询按钮使用 `.liquid-btn-primary`，含 `Sparkles` 图标
- 加载中时按钮切换为 `.liquid-btn-ai` 炫彩动效样式，显示旋转 Loader 图标和"AI 查询中..."文案
- 支持回车键触发查询

### 3.3 加载状态

- 查询中显示液态玻璃卡片，内含旋转 Loader 图标和提示文字"AI 正在分析您的问题并生成 SQL 查询..."
- 使用 CSS `@keyframes spin` 实现旋转动画

### 3.4 SQL 代码块展示

- 使用 `.liquid-code` 样式（规范 §5.9）
- 实现了 SQL 语法高亮函数 `highlightSQL()`：
  - **关键字**（SELECT, FROM, WHERE 等）：紫色 `#7c3aed`
  - **字符串**（单引号内容）：绿色 `var(--success)`
  - **数字**：金色 `var(--accent)`
  - **函数名**（COUNT, AVG, SUM 等）：蓝色 `#2563eb`
- 高亮顺序：先转义 HTML → 高亮字符串 → 高亮数字 → 高亮函数名 → 高亮关键字
- 右上角提供"复制 SQL"按钮，使用 `navigator.clipboard.writeText()`，复制后显示"已复制"反馈

### 3.5 查询结果表格

- 使用 `.liquid-table` 样式（规范 §5.8）
- 动态从查询结果中提取列名和行数据
- NULL 值显示为灰色占位文字
- 表格下方显示统计信息：
  - 记录条数（Database 图标）
  - 查询耗时（Clock 图标）
- 空结果显示"查询结果为空"提示

### 3.6 错误处理

- 使用 `.liquid-alert-error` 样式（规范 §5.11）
- 显示 AlertCircle 图标 + "查询出错"标题 + 错误详情
- 同时捕获网络错误和后端返回的业务错误

### 3.7 查询历史

- 每次查询（无论成功或失败）都记录到历史列表
- 最多保留 20 条历史记录
- 历史表格包含：问题、SQL、耗时、状态（成功/失败）、时间
- 成功显示绿色"成功"，失败显示红色"失败"

### 3.8 空状态提示

- 未进行任何查询时，显示 Sparkles 图标 + 提示文字
- 引导用户点击示例问题快速体验

## 四、状态管理

| 状态 | 类型 | 说明 |
|------|------|------|
| `question` | string | 当前输入的问题 |
| `loading` | boolean | 是否正在查询 |
| `result` | object/null | 查询结果 { sql, result, error, execution_time_ms } |
| `history` | array | 查询历史记录列表 |
| `copied` | boolean | SQL 是否已复制 |

## 五、API 调用

使用 `api/index.js` 中已封装的 `nl2sqlQuery` 函数：

```js
export const nl2sqlQuery = (question) => api.post('/nl2sql/query', { question });
```

后端返回格式：
```json
{
  "sql": "SELECT AVG(score) AS avg_score FROM exam_score ...",
  "result": [{ "avg_score": 11.5 }],
  "error": null,
  "execution_time_ms": 1523
}
```

## 七、与 Student 页面的风格一致性

NL2SQL 页面的实现风格与 Student.jsx 保持一致：
- 函数式组件 + 默认导出
- 使用 `useState`、`useCallback`、`useRef` 管理 state
- API 调用使用 `../api` 导出的函数
- 错误处理用 `.catch()` + 状态更新
- 样式使用内联 `style={{}}` + CSS 类名组合
- 使用 `LiquidCard` 包裹内容区块
- 使用 `lucide-react` 图标（Sparkles, Clock, Database, AlertCircle, Copy, Check, Loader）
- 加载/空态/错误态均有对应 UI 处理

## 九、后续优化方向

1. **查询历史持久化**：可将历史记录存储到 localStorage，刷新页面后不丢失
2. **历史记录点击重查**：点击历史记录中的问题可重新执行查询
3. **SQL 编辑功能**：允许用户在代码块中手动修改 SQL 后重新执行
4. **结果导出**：支持将查询结果导出为 CSV 文件
5. **分页展示**：查询结果较多时支持分页浏览
