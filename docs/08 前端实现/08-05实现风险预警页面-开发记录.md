## 一、任务目标

实现风险预警管理页面（Alert.jsx），包含以下功能：

1. 左右布局：左侧为重新生成预警按钮 + 风险分布饼图，右侧为预警列表表格 + 干预操作
2. 重新生成预警功能（调用 `POST /api/alerts/generate`）
3. 风险等级筛选（调用 `GET /api/alerts/?risk_level=xxx`）
4. 预警列表表格，含风险等级标签（risk-badge）、干预状态、分页
5. 干预操作表单（调用 `PUT /api/alerts/{id}/intervene`）
6. 风险分布饼图（调用 `GET /api/alerts/stats`）

## 三、实现细节

### 3.1 数据获取

页面加载时并行请求两个 API：
- `GET /api/alerts/`：获取预警列表（可选 `risk_level` 参数筛选）
- `GET /api/alerts/stats`：获取风险等级统计数据

```javascript
const fetchAlerts = useCallback(async () => {
  setLoading(true);
  try {
    const params = {};
    if (riskFilter) params.risk_level = riskFilter;
    const [alertsRes, statsRes] = await Promise.all([
      getAlerts(params),
      getAlertStats(),
    ]);
    setAlerts(Array.isArray(alertsRes.data) ? alertsRes.data : []);
    setAlertStats(statsRes.data);
  } catch (err) {
    console.error('获取预警数据失败:', err);
  } finally {
    setLoading(false);
  }
}, [riskFilter]);
```

### 3.2 重新生成预警

点击"重新生成预警"按钮时：
1. 调用 `POST /api/alerts/generate` 触发后端重新计算所有学生风险
2. 生成完成后自动刷新预警列表和统计数据
3. 生成过程中按钮显示 AI 炫彩动效（`liquid-btn-ai`），增强交互体验

### 3.3 风险分布饼图

使用 Recharts 的 `PieChart` 组件，严格遵循设计规范 §6 配色：
- 低风险：`#1a8a5a`（success 绿色）
- 中风险：`#d4880f`（warning 橙色）
- 高风险：`#c0392b`（danger 红色）

饼图中心镂空效果：64px 白色圆形 + `backdrop-filter: blur(4px)`，显示预警总数。

### 3.4 预警列表表格

使用 `.liquid-table` 样式，展示以下列：
- **ID**：预警编号
- **学生ID**：等宽字体显示
- **风险等级**：使用 `.risk-badge` 标签（`.risk-high` / `.risk-medium` / `.risk-low`）
- **风险评分**：根据分值动态着色（≥5 红色、≥3 橙色、其他主色深）
- **干预状态**：带图标的状态标签（待处理/进行中/已完成）
- **预警时间**：格式化为中文日期

分页功能：每页 15 条，底部显示分页控件。

### 3.5 筛选功能

使用自定义 `LiquidSelect` 组件（替代原生 `<select>`），选项包括：
- 全部等级
- 高风险
- 中风险
- 低风险

切换筛选时自动重置页码并重新请求数据。

### 3.6 干预操作

干预操作区域使用 `.liquid-card` 包裹，包含：
- **预警 ID** 输入框（`.liquid-input`，number 类型）
- **干预状态** 下拉框（`LiquidSelect` 组件，选项：待处理/进行中/已完成）
- **干预措施** 输入框（`.liquid-input`，支持 Enter 快捷提交）
- **更新** 按钮（`.liquid-btn`）

提交后显示成功/错误提示（`.liquid-alert-success` / `.liquid-alert-error`），成功提示 3 秒后自动消失。

## 七、与 PLAN.md 的差异说明

1. **表格列增加"风险评分"列**：PLAN.md 原始布局只有 ID/学生/等级/状态 四列，实现时增加了风险评分列，便于直观了解风险程度
2. **增加分页功能**：预警数据量较大时（数千条），添加了前端分页（每页 15 条），提升用户体验
3. **生成按钮使用 AI 炫彩动效**：生成过程中按钮切换为 `liquid-btn-ai` 样式，与其他页面的 AI 操作保持一致
4. **干预操作使用 Grid 布局**：表单项使用 `grid-template-columns: 100px 1fr 1fr auto`，比纯行内布局更整齐
5. **自定义 LiquidSelect 组件替代原生 `<select>`**：原生 `<select>` 的下拉选项面板由 OS 渲染，无法应用液态玻璃效果（半透明背景、backdrop-filter 模糊、顶部高光线等），导致与整体风格严重不协调。因此创建了 `LiquidSelect` 组件，触发器和下拉面板均采用 Liquid Glass 设计，同时更新了设计规范文档 §5.6
