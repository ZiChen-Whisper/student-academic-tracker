## 三、详细实现过程

### 3.1 后端 API 增强

**问题**：原 `GET /api/students/<student_id>` 只返回 student 表数据，前端无法获取学习行为和家庭背景信息。

**解决方案**：在 `backend/routes/student.py` 的 `get_student` 路由中增加关联查询：

- 查询 `learning_behavior` 表，获取出勤率、学习时长、睡眠时长、动机水平等
- 查询 `family_background` 表，获取父母教育/职业、家庭收入、家庭支持等
- 将结果作为 `behavior` 和 `family` 字段嵌入学生详情 JSON 返回
- 移除冗余字段（behavior_id、student_id、record_date、family_id）

**验证结果**：
- `STU_F_0001`（Performance Factors 数据集学生）：behavior 和 family 数据均正确返回
- `STU_M_0001`（UCI 数据集学生）：behavior 为 null（UCI 数据集无学习行为记录），family 数据正确返回

### 3.2 LiquidCard 组件增强

**修改**：添加 `style` prop，允许外部传入自定义样式。

export default function LiquidCard({ title, children, className = '', style }) {

### 3.3 MetricCard 组件增强

### 3.4 Student.jsx 页面实现

#### 页面结构

```
┌─────────────────────────────────────────────────┐
│  学生详情                                        │
│  [搜索学生...                    ] [搜索]         │
├─────────────────────────────────────────────────┤
│  [成绩趋势] [学习行为] [家庭背景] [预警与建议]    │
├─────────────────────────────────────────────────┤
│  （Tab 内容区域 - 液态玻璃卡片）                  │
└─────────────────────────────────────────────────┘
```

#### 核心功能实现

**1. 学生搜索**
- 使用 `liquid-input` + `liquid-btn-primary` 组合
- 支持回车键搜索
- 搜索结果在 `liquid-card` 中展示，每项包含头像（首字）、姓名、学号、性别、班级
- 点击搜索结果项加载学生详情
- hover 效果：`rgba(11,101,101,0.06)` 背景

**2. 学生信息卡片**
- 使用 `liquid-card` 展示头像、姓名、学号、性别、年龄、班级
- 右侧显示风险等级标签（如有预警数据）
- 头像使用 `liquid-avatar` 组件，取姓名首字

**3. Tab 切换**
- 使用 `liquid-tabs` + `liquid-tab` 组件
- 4 个 Tab：成绩趋势（BookOpen 图标）、学习行为（Brain 图标）、家庭背景（Home 图标）、预警与建议（AlertTriangle 图标）
- active 态：白底浮起 + 阴影，主色文字（遵循规范 §5.7）

**4. 成绩趋势 Tab**
- 使用 Recharts `LineChart`，x 轴为 exam_stage（G1/G2/G3），y 轴为 score
- 按科目分组绘制多条折线：
  - SUBJ_MATH：主色 `#0b6565`（实线）
  - SUBJ_PORTUGUESE：辅色 `#c9933a`（虚线）
  - SUBJ_GENERAL：`#1a8a5a`（虚线）
- 网格线：`rgba(11,101,101,0.05)`，0.5px
- 坐标轴文字：`rgba(11,101,101,0.35)`
- Tooltip：`rgba(0,0,0,0.7)` 背景，白色文字
- Legend 使用 SUBJECT_MAP 将科目 ID 映射为中文名

**5. 学习行为 Tab**
- 使用 `MetricCard` 网格（3列），展示 6 项指标：
  - 出勤率：`attendance_rate%`，低于 80% 显示 danger 色
  - 学习时长：`study_hours h/周`
  - 睡眠时长：`sleep_hours h/天`
  - 动机水平：Low=danger, Medium=warning, High=success
  - 辅导次数：`tutoring_sessions 次`
  - 网络接入：Yes=success, No=danger

**6. 家庭背景 Tab**
- 使用 `liquid-table` 表格展示键值对
- 展示字段：父亲教育、母亲教育、父亲职业、母亲职业、家庭收入、家庭支持、家长参与度、家庭关系评分
- 自动过滤空值字段

**7. 预警与建议 Tab**
- **预警信息**：
  - 每条预警显示风险等级标签（risk-badge）、时间、干预状态
  - 风险因素解析（JSON 数组 → 分号分隔字符串）
  - 干预措施显示
  - 干预状态标签：completed=绿色、in_progress=橙色、pending=灰色
- **AI 学习建议**：
  - "生成学习建议"按钮使用 `liquid-btn-primary` + Sparkles 图标
  - 建议列表：每条显示时间、内容、反馈状态
  - 反馈按钮：满意/一般/不满意，使用 `liquid-btn-sm`
  - 反馈提交后实时更新 UI

#### 数据流

```
用户搜索 → searchStudents API → 搜索结果列表
用户选择 → Promise.all([
  getStudent(id),      → behavior + family 数据
  getScoreTrend(id),   → 成绩趋势数据
  getAlerts(),         → 筛选当前学生预警
  getSuggestions(id),  → 建议列表
])
```

## 五、遇到的问题与解决

### 问题 1：后端 API 不返回 behavior 和 family 数据

**原因**：`GET /api/students/<id>` 只查询 student 表。

**解决**：在 `student.py` 的 `get_student` 路由中增加对 `learning_behavior` 和 `family_background` 表的关联查询，将结果作为嵌套字段返回。

### 问题 2：LiquidCard 不支持 style prop

**原因**：搜索结果列表需要自定义 padding，但 LiquidCard 未暴露 style prop。

**解决**：在 LiquidCard 组件中添加 `style` prop 并传递给外层 div。

### 问题 3：MetricCard 图标不足

**原因**：学习行为 Tab 需要 6 种不同图标，但 MetricCard 只映射了 4 种。

**解决**：在 MetricCard 中添加 Clock、Moon、Brain、GraduationCap、Wifi 五种图标映射。

### 问题 4：HMR 报错 Brain is not defined

**原因**：清理 Student.jsx 导入时误删了 Brain 图标，但 TABS 定义中仍在使用。

**解决**：将 Brain 重新加入 lucide-react 导入列表。

## 七、后续优化建议

1. **搜索优化**：当前搜索需点击按钮或回车，可改为防抖自动搜索
2. **预警筛选**：当前获取全部预警后前端筛选，数据量大时可改为后端按 student_id 筛选
3. **成绩趋势增强**：可添加班级平均线作为对比参考
4. **建议分页**：建议内容较长时，可添加分页或折叠功能
