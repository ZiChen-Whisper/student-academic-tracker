# 如何运行本项目

## 快速开始（推荐）

如果你是第一次运行本项目，只需按顺序执行以下两步：

### 第一步：导入数据库

双击运行 `database\导入数据库.bat`，按提示输入 MySQL 用户名和密码即可。

> 脚本会自动创建 `student_academic_tracker` 数据库并导入全部数据（约 7MB，包含 7000+ 学生、69000+ 条成绩记录）。

### 第二步：配置数据库连接

1. 将 `backend\.env.example` 复制为 `backend\.env`
2. 编辑 `backend\.env`，填写你的 MySQL 密码：

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_NAME=student_academic_tracker
```

> AI 功能（NL2SQL、风险预警、学习建议）需要配置 DeepSeek API Key，如不需要可跳过。

### 第三步：一键启动

双击运行 `一键启动.bat`，脚本会自动：
- 检查 Python 和 Node.js 环境
- 首次运行自动安装依赖
- 启动后端和前端
- 打开浏览器

---

## 手动运行（详细步骤）

如果一键脚本无法正常工作，可以按以下步骤手动运行。

### 前提条件

| 软件 | 用途 | 检查方法 | 下载地址 |
|------|------|---------|---------|
| Python 3.10+ | 运行后端 | `python --version` | https://www.python.org/downloads/ |
| Node.js 18+ | 运行前端 | `node --version` | https://nodejs.org/ （LTS 版本） |
| MySQL 8.0+ | 数据库 | `mysql --version` | https://dev.mysql.com/downloads/ |

> 安装 Python 和 Node.js 时务必勾选 **"Add to PATH"**。

---

### 第一步：导入数据库

#### 方式 A：使用导入脚本

双击 `database\导入数据库.bat`，按提示操作。

#### 方式 B：手动导入

```bash
# 在项目根目录打开终端
mysql -u root -p --default-character-set=utf8mb4 < database\student_academic_tracker.sql
```

输入密码后等待导入完成（约几秒到十几秒）。

#### 验证导入结果

```sql
USE student_academic_tracker;
SELECT COUNT(*) FROM student;  -- 应返回约 7451
SELECT COUNT(*) FROM exam_score;  -- 应返回约 69130
```

---

### 第二步：配置后端

1. 复制配置文件模板：
   ```bash
   cd backend
   copy .env.example .env
   ```

2. 编辑 `backend\.env`，填写你的 MySQL 密码：
   ```env
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=你的MySQL密码
   DB_NAME=student_academic_tracker

   # AI 功能配置（可选，不影响基本功能）
   LLM_API_KEY=你的DeepSeek API Key
   LLM_BASE_URL=https://api.deepseek.com
   LLM_MODEL=deepseek-chat
   ```

---

### 第三步：启动后端

```bash
cd backend

# 首次运行安装依赖
pip install -r requirements.txt
# 下载慢可用国内镜像：
# pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 启动后端
python app.py
```

看到以下输出说明启动成功：
```
 * Serving Flask app 'app'
 * Debug mode: on
 * Running on http://127.0.0.1:5000
```

> 终端窗口不要关闭，后端需要一直运行。

---

### 第四步：启动前端

**新开一个终端窗口**（不要关闭后端的终端）：

```bash
cd frontend

# 首次运行安装依赖
npm install

# 启动前端
npm run dev
```

看到以下输出说明启动成功：
```
  VITE v8.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
```

---

### 第五步：打开浏览器

访问 http://localhost:5173 ，你将看到学情概览页面，包含：
- 4 个指标卡片（学生总数、平均成绩、高风险学生、及格率）
- 各科目平均成绩柱状图
- 风险等级分布饼图
- 成绩分布直方图

## 常见问题

### Q1: 页面指标卡片显示 "--"，图表显示"暂无数据"

**原因**：后端未启动或启动失败。

**解决**：
1. 确认后端终端窗口还开着，且显示 `Running on http://127.0.0.1:5000`
2. 浏览器访问 http://localhost:5000/api/scores/overview ，看是否有 JSON 数据
3. 如果无数据，检查后端终端的报错信息

### Q2: 后端报错 `mysql.connector.errors.DatabaseError`

**原因**：数据库连接失败。

**解决**：
1. 确认 MySQL 服务正在运行
2. 检查 `backend\.env` 中的 `DB_PASSWORD` 是否正确
3. 确认数据库 `student_academic_tracker` 已导入（运行 `导入数据库.bat`）

### Q3: 导入数据库脚本报错 "未找到 mysql 命令"

**原因**：MySQL 未添加到系统 PATH。

**解决**：
1. 找到 MySQL 安装目录（如 `C:\Program Files\MySQL\MySQL Server 8.0\bin`）
2. 将该路径添加到系统环境变量 PATH
3. 或在脚本中输入完整路径运行

### Q4: `npm install` 报错或 `npm` 不是命令

**原因**：Node.js 未安装。

**解决**：
1. 访问 https://nodejs.org/ 下载 LTS 版本
2. 安装时勾选 **"Add to PATH"**
3. 安装后**重新打开**终端

### Q5: `pip install` 报错

**原因**：Python 未安装或版本过低。

**解决**：
1. 访问 https://www.python.org/downloads/ 下载 Python 3.10+
2. 安装时勾选 **"Add Python to PATH"**
3. 重新打开终端

### Q6: 端口被占用

- 前端端口 5173 被占用：Vite 会自动尝试 5174、5175...，直接用新端口即可
- 后端端口 5000 被占用：先关闭占用进程，或修改 `backend\app.py` 中的端口号

### Q7: AI 功能（NL2SQL、风险预警）不工作

**原因**：未配置 DeepSeek API Key。

**解决**：
1. 在 `backend\.env` 中填写 `LLM_API_KEY`
2. 如无 API Key，基本功能（学情概览、学生详情、数据管理）仍可正常使用

## 每次运行只需 3 步

```
1. 确保 MySQL 在运行
2. 双击 一键启动.bat
3. 浏览器自动打开 http://localhost:5173
```

> 首次运行需先导入数据库和配置 `.env`，之后每次只需双击 `一键启动.bat`。
