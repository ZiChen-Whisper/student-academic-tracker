# 如何运行本项目 — 详细步骤指南

## 前提条件

在运行之前，请确保你的电脑已安装以下软件：

| 软件 | 用途 | 检查方法 | 下载地址 |
|------|------|---------|---------|
| Python 3.10+ | 运行后端 | 打开终端输入 `python --version` | https://www.python.org/downloads/ |
| Node.js 18+ | 运行前端 | 打开终端输入 `node --version` | https://nodejs.org/ （下载 LTS 版本） |
| MySQL | 数据库 | 打开终端输入 `mysql --version` | https://dev.mysql.com/downloads/ |

> 如果 `python --version` 或 `node --version` 报错"找不到命令"，说明还没安装或没加入环境变量。

---

## 第一步：确保 MySQL 数据库在运行

1. 打开 MySQL Workbench 或命令行，连接到你的 MySQL 服务器
2. 确认数据库 `student_academic_tracker` 存在且有数据：
   ```sql
   USE student_academic_tracker;
   SELECT COUNT(*) FROM student;
   ```
   应该返回一个数字（如 7653），说明数据库正常。

> 如果数据库还没创建，需要先执行建表脚本（在 `前期准备/04 ER图转关系模式/建表脚本.sql`）和数据导入。

---

## 第二步：启动后端（Flask）

### 2.1 打开一个终端窗口

- Windows：按 `Win + R`，输入 `cmd`，回车
- 或者用 VS Code / Trae 的内置终端

### 2.2 进入后端目录

```bash
cd "d:\大二下资料\数据库原理\大作业\student-academic-tracker\backend"
```

### 2.3 激活 Python 虚拟环境（如果有）

```bash
# 如果你之前创建过 venv 虚拟环境：
venv\Scripts\activate

# 如果没有虚拟环境，跳过这步，直接用系统 Python
```

### 2.4 安装 Python 依赖（第一次运行时需要）

```bash
pip install -r requirements.txt
```

> 如果下载慢，可以用国内镜像：
> ```bash
> pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

### 2.5 启动后端

```bash
python app.py
```

看到以下输出说明启动成功：

```
 * Serving Flask app 'app'
 * Debug mode: on
 * Running on http://127.0.0.1:5000
```

> **注意**：这个终端窗口要保持开着，不要关闭！后端运行期间需要一直保持。

---

## 第三步：启动前端（React + Vite）

### 3.1 再打开一个新的终端窗口

> **重要**：不要关闭第二步的终端！需要再开一个新终端。

### 3.2 进入前端目录

```bash
cd "d:\大二下资料\数据库原理\大作业\student-academic-tracker\frontend"
```

### 3.3 安装前端依赖（第一次运行时需要）

```bash
npm install
```

> 如果报错"npm 不是命令"，说明 Node.js 没安装或没加入环境变量，请先安装 Node.js。

### 3.4 启动前端

```bash
npm run dev
```

看到类似以下输出说明启动成功：

```
  VITE v8.0.16  ready in 468 ms

  ➜  Local:   http://localhost:5173/
```

> 端口号可能不同（如 5174、5175），以实际输出为准。

## 常见问题

### Q1: 打开页面后指标卡片显示 "--"，图表显示"暂无数据"

**原因**：后端没有启动，或者后端启动失败。

**解决**：
1. 确认第二步的终端窗口还开着，且显示 `Running on http://127.0.0.1:5000`
2. 在浏览器新标签页访问 `http://localhost:5000/api/scores/overview`，看是否有 JSON 数据返回
3. 如果 5000 端口无法访问，检查后端终端是否有报错信息

### Q2: 后端启动报错 `mysql.connector.errors.DatabaseError`

**原因**：数据库连接失败。

**解决**：
1. 确认 MySQL 服务正在运行
2. 检查 `backend/.env` 文件中的数据库密码是否正确
3. 确认数据库 `student_academic_tracker` 已创建

### Q3: `npm install` 报错或 `npm` 不是命令

**原因**：Node.js 未安装。

**解决**：
1. 访问 https://nodejs.org/ 下载 LTS 版本安装
2. 安装时勾选"Add to PATH"
3. 安装后**重新打开**终端窗口，再试 `node --version`

### Q4: `pip install` 报错

**原因**：Python 未安装或版本过低。

**解决**：
1. 访问 https://www.python.org/downloads/ 下载 Python 3.10+
2. 安装时勾选"Add Python to PATH"
3. 重新打开终端再试

### Q5: 端口被占用

如果 `python app.py` 报端口 5000 被占用，或 `npm run dev` 报端口 5173 被占用：

- Vite 会自动尝试下一个端口（5174、5175...），直接用新端口即可
- Flask 端口冲突需要先关闭占用进程，或修改 `backend/app.py` 中的端口号

### Q6: 页面打开是空白

1. 按 `F12` 打开浏览器开发者工具，查看 Console 标签是否有红色报错
2. 确认地址栏输入的是 `http://localhost:5173`（不是 5000）

---

## 总结：每次运行只需要 3 步

```
1. 确保 MySQL 在运行
2. 在终端1中：cd backend → python app.py       （启动后端）
3. 在终端2中：cd frontend → npm run dev        （启动前端）
4. 浏览器打开 http://localhost:5173
```

> 第一次运行时，步骤 2 和 3 需要先安装依赖（`pip install -r requirements.txt` 和 `npm install`），之后就不需要了。
