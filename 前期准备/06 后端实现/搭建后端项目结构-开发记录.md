### 步骤 4：验证数据库连接

执行验证命令：

```bash
python -c "import sys; sys.path.insert(0,'backend'); from db import query_one; print(query_one('SELECT COUNT(*) AS cnt FROM student'))"
```

**初次结果：** 连接失败，报错 `Access denied for user 'root'@'localhost' (using password: NO)`

**原因分析：** `backend/.env` 文件实际已存在且配置正确，但 `config.py` 中的 `load_dotenv()` 不带参数时默认从**当前工作目录**查找 `.env` 文件。验证命令从项目根目录运行，而 `.env` 位于 `backend/` 子目录，导致 `load_dotenv()` 找不到它，密码回退为空字符串。

**修复方案：** 修改 `backend/config.py`，让 `load_dotenv()` 明确指向 `config.py` 同目录下的 `.env` 文件：

```python
# 修改前
load_dotenv()

# 修改后
load_dotenv(os.path.join(os.path.dirname(os.path.abspath(__file__)), '.env'))
```

**修复后验证结果：** ✅ 连接成功，输出 `{'cnt': 7655}`
